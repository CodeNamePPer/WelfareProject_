# ต้นแบบดีไซน์ HR + หัวหน้า HR

ไฟล์ `.dc.html` หนึ่งไฟล์ = หนึ่งหน้า เป็นต้นแบบหน้าตาเท่านั้น (ข้อมูลในไฟล์เป็นตัวอย่าง ของจริงต้องดึงจาก Supabase)

วิธีอ่าน
- เนื้อหาหน้าอยู่ใน `<x-dc>` ใช้ inline style ทั้งหมด ให้ยึดสี ขนาด ระยะห่าง และข้อความตามนี้
- `{{ ชื่อ }}` คือค่าที่เปลี่ยนตาม state, `<sc-if value="{{ x }}">` คือส่วนที่แสดงตามเงื่อนไข, logic ตัวอย่างอยู่ใน `<script type="text/x-dc">` ท้ายไฟล์
- `href="X.dc.html"` คือลิงก์ไปหน้านั้น
- ความกว้างต้นแบบ 1440px: Sidebar 260px + เนื้อหา max-width 1140px
