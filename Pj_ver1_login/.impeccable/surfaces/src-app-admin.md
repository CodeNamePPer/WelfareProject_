# Surface: /admin (ผู้ดูแลระบบ)

Mode: Operate. Audience: IT/ผู้ดูแลระบบ 1–3 คน เปิดทุกเช้าเพื่อเคลียร์งานค้าง บนคอมพิวเตอร์ในออฟฟิศ (แสงกลางวัน → light).
Job: รู้ทันทีว่าต้องทำอะไร อะไรรอ HR อนุมัติ และมีปัญหาอะไร แล้วไปแก้ได้ในคลิกเดียว.
Constraints: คงสีน้ำเงิน primary-600, type scale Figma (body 13px), IBM Plex Sans Thai; ไม่แตะ /hr (Sidebar สีปกใช้เฉพาะ section admin).
Reviewer feedback to answer: ดูเหมือน wireframe / AI template, การ์ดทุกส่วน, หน้าแรกโชว์ตัวเลขแทนงาน.

## Direction contract

THESIS: หน้า Admin เขียนเหมือนหน้าสมุดนักเรียนปกน้ำเงิน: งานเรียงเป็นบรรทัดคั่นเส้นฟ้า เวลาค้างอยู่หลังเส้นกั้นหน้าสีแดง ปฏิเสธ bento grid ของการ์ดตัวเลข KPI.

OWN-WORLD: Sidebar ปกน้ำเงินเข้ม #1E3A8A ตัวอักษรฟ้าซีด เมนูที่เลือกเป็นแถบขาวเหมือนป้ายชื่อหน้าปก. พื้นเนื้อหาขาว ไม่มีกล่องการ์ด; หัวส่วนเป็นหัวข้อ + เส้นน้ำเงินเข้ม 2px ใต้หัว; แถวคั่นด้วยเส้นฟ้า #DCE6F5; คอลัมน์เวลาแยกด้วยเส้นกั้นหน้าแดง 1px (#C2362B). น้ำเงิน primary สงวนให้สิ่งที่กดได้/เลือกอยู่, แดงสงวนให้เกินกำหนด/อันตราย, อำพันให้รอ, เขียวให้เสร็จ. Tag มุม 4px. ตัวเลขและรหัสใช้ tabular-nums.

STORY: Admin เปิดมาเห็นป้ายชื่อหน้า (หน้า/วันที่/ผู้ดูแล) แถบสรุปบรรทัดเดียว แล้วไล่บรรทัด: ต้องจัดการ → รอ HR อนุมัติ → ปัญหาระบบ. กดปุ่มท้ายบรรทัดเพื่อไปแก้.

FIRST VIEWPORT: ซ้าย sidebar ปก 260px. ขวา: ป้ายชื่อหน้าแบ่งช่อง (หน้า | วันที่ | ผู้ดูแล) เส้นน้ำเงินเข้มใต้, แถบสรุป 4 ค่า (เกินกำหนดเป็นแดง), กลุ่ม "ต้องจัดการ" เต็มกว้าง แต่ละบรรทัด: เวลาค้าง | เส้นแดง | รหัส | เรื่อง | ประเภท | ปุ่มลงมือ. ใต้ลงมาสองคอลัมน์: "รอ HR อนุมัติ" และ "ปัญหาระบบ". ด้านล่างสุด: กิจกรรมล่าสุด และสถิติรายบุคคลเป็นตาราง.
